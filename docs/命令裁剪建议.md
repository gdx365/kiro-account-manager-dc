## 执行建议

1. 先为 `internal` / `deprecated` 命令在代码中加状态注释（或集中注册表）。
2. `deprecated` 先从文档/入口下线，观察一个版本。
3. 下一版本再移除 `main.rs` 注册与实现，并保留迁移说明。
4. 每次裁剪后执行：`npm run check:commands && npm run build && cargo test`。
