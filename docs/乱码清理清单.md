# 乱码清理清单（首轮扫描）

生成时间：2026-05-06

说明：基于 `npm run check:encoding` 输出，当前检测到约 1500 行可疑乱码。以下优先级按“用户可见影响”和“运行时风险”排序。

## P0（用户直接可见）

1. `locales/zh-CN.json`
- 现状：大量中文翻译为乱码，直接影响 UI 文案显示。
- 风险：界面不可读，功能可用性下降。

2. `src-tauri/tauri.conf.json`
- 现状：应用描述字段乱码（`shortDescription` / `longDescription`）。
- 风险：安装包/系统展示文案异常。

3. `index.html`
- 现状：启动页文案乱码。
- 风险：首屏体验受损。

## P1（开发维护风险高）

4. `src-tauri/src/main.rs`
- 现状：大量注释与日志字符串乱码。
- 风险：排障日志可读性差，维护成本高。

5. `src/` 下多处组件注释
- 现状：注释乱码广泛存在。
- 风险：理解代码困难，重构风险增加。

## P2（文档类）

6. `AGENTS.md`、`HALL_OF_SHAME.md` 等文档
- 现状：内容乱码。
- 风险：团队协作与规范传达失真。

## 建议执行顺序

1. 先修 `locales/zh-CN.json`、`tauri.conf.json`、`index.html`。
2. 再修 `src-tauri/src/main.rs` 的注释与日志文案。
3. 最后批量清理文档与非关键注释。
